## Лабораторная работа № 1

**Тема:** Среда, репозиторий и первый взгляд на данные.

**Вариант:** 7.

В работе выполнены:
- анализ структуры и характеристик датасета;
- проверка размеров изображений, цветовых каналов и форматов файлов;
- анализ наличия XML-разметки;
- базовые преобразования изображений;
- сохранение статистики и визуализаций.

Подробности и результаты доступны в [отчёте по лабораторной работе № 1](lab01/README.md).

## Лабораторная работа № 2

**Тема:** Классическая обработка изображений.

**Вариант:** 5.

В работе выполнены:
- анализ характеристик изображений: яркости, контраста, уровня шума и резкости;
- исследование методов коррекции освещённости;
- сравнение фильтров подавления шума по PSNR, SSIM и времени выполнения;
- реализация классической сегментации животных без использования нейронных сетей;
- исследование влияния пороговой обработки и морфологических операций на качество сегментации;
- оценка результатов с помощью IoU и анализ признаков формы объектов.

### Структура

- `lab02/solution.ipynb` — ноутбук с кодом и результатами выполнения;
- `lab02/README.md` — отчёт по лабораторной работе;
- `lab02/results/` — таблицы с метриками и итоговые визуализации.

Подробности и результаты доступны в [отчёте по лабораторной работе № 2](lab02/README.md).
