## Лабораторная работа № 1

**Тема:** Среда, репозиторий и первый взгляд на данные.

**Вариант:** 7.

В работе выполнены:
- анализ структуры и характеристик датасета;
- проверка размеров изображений, цветовых каналов и форматов файлов;
- анализ наличия XML-разметки;
- базовые преобразования изображений;
- сохранение статистики и визуализаций.

### Структура
